KBForms pour Android

Version de test destinée aux enquêteurs de terrain (collecte hors-ligne, synchronisation automatique). Pas encore publiée sur le Play Store : installation manuelle du fichier APK.

Télécharger l'APK

Le fichier n'est pas encore disponible en ligne. Reviens plus tard ou contacte l'administrateur.

Installation sur le téléphone

  1. Ouvre cette page depuis le téléphone Android et appuie sur Télécharger l'APK.
  2. À l'ouverture du fichier, Android demande d'autoriser l'installation depuis cette source (Paramètres → Applications → Accès spécial → Installer des applis inconnues) : accepte.
  3. Appuie sur Installer, puis Ouvrir.
  4. Connecte-toi avec le compte enquêteur (ou les identifiants d'agent reçus par email).

Pour mettre à jour l'application plus tard, il suffit de réinstaller la nouvelle version APK par-dessus l'ancienne — les données locales sont conservées.
